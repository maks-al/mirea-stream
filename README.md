# mirea-stream
Онлайн платформа видеоконференцсвязи, основанная на Jitsi Meet версии `stable-11248-2`.
Разворачиваются контейнеры `web`, `prosody`, `jicofo`, `jvb`, `nginx`, применены Docker Compose, одноузловой Docker Swarm и GitHub Actions CI/CD.

Нужно получить исходный пакет Jitsi непосредственно с официального GitHub и сохранить его в `upstream/`.

Перед выполнением команд обязательно убедиться что свободны порты 80/TCP, 443/TCP, 10000/UDP и указан DNS (в данном случае `mirea.stream`). На VPS с существующими сервисами автоматическое изменение сетевых правил или удаление контейнеров недопустимо и потребовало бы повторной переустановки с изменением опций.

Swarm-конфигурация генерируется из проверенной Compose-конфигурации скриптом `scripts/render-swarm.py`
